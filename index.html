Configuración
Pegá la URL que te da Apps Script al desplegar la Web App.
1. Creá un Google Sheet nuevo → copiá el ID de la URL.
2. Abrí Extensiones → Apps Script dentro del Sheet.
3. Pegá el código del archivo apps_script.js y reemplazá TU_SPREADSHEET_ID_AQUI con tu ID.
4. Ejecutá la función setup_inicial() una sola vez.
5. Ir a Implementar → Nueva implementación → App web → Ejecutar como: Yo · Acceso: Cualquier persona.
6. Copiá la URL y pegala arriba.
